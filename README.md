# Dongyi Zhang's Academic Homepage

This repository contains the source for https://leduo112.github.io.

Edit `_pages/about.md` to update homepage content. Update `_config.yml` for site metadata and profile links, and `_data/navigation.yml` for the page navigation.

To preview locally:

```sh
bundle exec jekyll serve
```

The profile photo is `images/profile.jpg`. Publication figures are `images/tag.png` and `images/buildings.png`. The CV section is currently commented out in `_pages/about.md`.
